# 短屏首页交互提案（待确认）

入口：`home-short-screen-interaction-review.html`。用户反馈单纯压缩行和间距无法解决首屏占比，因此本稿不改变现有标准屏，也不继续压缩交易行。

- **A 轻摘要＋底部概览抽屉（建议）**：支出和预算剩余常驻；点击一次查看完整收入、结余、月预算与进度，关闭后保持明细位置。初次进入就释放高度，代价是部分汇总需要展开。
- **B 滚动收起**：完整汇总仍在顶部，页面整体向下滚动后出现吸顶摘要；点击摘要回到完整汇总。习惯变化最小，但不能改善初次进入时的占比。
- **C 明细／本月概览双视图**：默认明细，切换查看完整汇总。列表 DOM 不重建、保持滚动位置；代价是核对明细与汇总需要切换。

375×667、320×568 为主要对象；398×844 仅用于比较，落地后普通屏沿用现有交互。稿中可切换浅深色、100%／140% 字号、预算未设置／正常／超支。月份和隐私复用主 Demo，明细复用同一份交易行，不改行高来夸大收益。

全部数字为本地合成示例，不代表真实财务数据；预算弹层只用于演示入口。确认交互后再明确短屏触发条件、是否记忆展开状态及预算管理的原生导航，不提前改 Flutter。
